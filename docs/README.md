# Kumbara web sayfaları

App Store için zorunlu iki sayfa:

- `index.html` — Destek URL'si (SSS ve iletişim)
- `privacy.html` — Gizlilik politikası URL'si

Dış betik ya da yazı tipi yok; her sayfa tek başına çalışır.

## GitHub Pages'i açma

1. GitHub'da depo › **Settings › Pages**.
2. **Source:** "Deploy from a branch"; **Branch:** `main`, klasör **`/docs`** › **Save**.
3. Birkaç dakika sonra sayfalar şu adreslerde yayında olur:
   - `https://<kullanıcı>.github.io/kumbara/`
   - `https://<kullanıcı>.github.io/kumbara/privacy.html`

## Yayından önce

İki sayfadaki iletişim adresi `destek@ALAN-ADI` bir **yer tutucudur**; App Store'a
göndermeden önce gerçek destek adresiyle değiştirilmelidir.
